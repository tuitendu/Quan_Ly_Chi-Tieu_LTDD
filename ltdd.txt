# Ung dung Quan ly Chi tieu - Dark Mode
# Cong nghe: Android Native | Java + XML | SQLite | Gradle

## Y tuong tong the

App giup nguoi dung co gang tiet kiem moi thang bang cach ghi lai luong, chi phi co dinh, chi phi phat sinh theo ngay. So du hien thi la tong lương tất cả tháng trừ tổng tất cả chi tiêu đã ghi nhận.

---

## Cac loai du lieu

### Chi phi co dinh (fixed)
- La nhung khoan chi tra hang thang: tien tro, dien nuoc, internet, xang xe, v.v.
- Gan theo THANG hien tai - user tu nhap lai moi thang neu muon ghi nhan.
- Luu vao SQLite voi category = "fixed", date = "yyyy-MM" (vi du: 2026-03).
- Tab CHI PHI CO DINH chi hien fixed cua THANG HIEN TAI.
- Thang sau neu them khoan co dinh moi -> chi tinh tu thang do tro di.
- getTotalBalanceAllTime() cong DAN TAT CA fixed moi thang -> chinh xac.

### Chi phi phat sinh (variable)
- Nhung khoan chi ngau nhien trong ngay: an uong, di choi, mua do, v.v.
- Chi show chi phi phat sinh cua ngay hom nay tren giao dien.
- Luu SQLite voi category = "variable", date = "yyyy-MM-dd".
- Du lieu cu (ngay khac) van giu trong database de thong ke.

### Luong thang (salary)
- Moi thang nguoi dung nhap luong du kien cho thang do.
- Luu SQLite voi category = "salary", date = "yyyy-MM".
- Moi thang chi co 1 ban ghi salary.
- Neu thang nay chua co: nut hien "Cap nhat" -> bam se INSERT moi.
- Neu thang nay da co: nut hien "Sua" -> bam se UPDATE dung ban ghi do.
- Truoc day luu SharedPreferences, da chuyen sang DB tu phien lam viec nay.

## Database (SQLite)

Cach luu tru nay goi la: SQLite - Co so du lieu quan he (Relational Database)
- Du lieu to chuc thanh bang (table), hang (row), cot (column)
- Moi hang = 1 ban ghi (record)
- Truy van bang SQL (Structured Query Language)
- Android tich hop san SQLite, khong can cai them gi
- File DB luu tai: data/data/com.example.gk/databases/expense_db
- Ten DB: expense_db | Phien ban (version): 2

### Bang: expenses - cot

    id       INTEGER PRIMARY KEY AUTOINCREMENT
    amount   REAL
    note     TEXT
    category TEXT  ->  "variable" | "fixed" | "salary" | "income"
    date     TEXT  ->  format khac nhau tuy category

### Bang: expenses - du lieu mau

    id | amount  | note                   | category | date
    ---|---------|------------------------|----------|----------
    1  | 5000000 | Luong thang 2026-03    | salary   | 2026-03
    2  | 1500000 | Tien tro               | fixed    | 2026-03
    3  | 800000  | Dien nuoc              | fixed    | 2026-03
    4  | 50000   | Ca phe sang            | variable | 2026-03-22
    5  | 120000  | An trua                | variable | 2026-03-22
    6  | 5000000 | Luong thang 2026-04    | salary   | 2026-04
    7  | 1500000 | Tien tro               | fixed    | 2026-04
    8  | 200000  | Di choi                | variable | 2026-04-01

So du = (5M + 5M) - (1.5M + 0.8M + 0.05M + 0.12M + 1.5M + 0.2M) = 5,830,000 d

### Cac ham chinh trong DatabaseHelper.java

    addExpense(amount, note, category, date)     - them ban ghi moi
    deleteExpense(id)                            - xoa ban ghi theo id
    updateExpenseAmount(id, newAmount)           - sua so tien theo id
    getFixedExpenses()                           - lay tat ca category="fixed" (moi thang, dung cho balance)
    getFixedExpensesForMonth(month)              - lay category="fixed" cua dung thang "yyyy-MM" (dung cho UI tab)
    getVariableExpenses(date)                    - lay category="variable" theo ngay
    getIncomes()                                 - lay tat ca category="income"
    getSalaryForMonth(month)                     - lay luong cua thang "yyyy-MM"
    getTotalForDate(date)                        - tong variable ngay do + tong tat ca fixed
    getTotalVariableForDate(date)                - chi tong variable ngay do
    getTotalIncome()                             - tong tat ca income
    getTotalBalanceAllTime()                     - So du = tong salary - tong (variable+fixed moi thang)

## Logic chinh

### Tinh so du
    So du = SUM(amount WHERE category='salary') - SUM(amount WHERE category IN ('variable','fixed'))

### Nut Cap nhat / Sua
    Mo fragment -> getSalaryForMonth(yyyy-MM)
      neu null   -> setText("Cap nhat"), currentSalaryId = -1
      neu co     -> setText("Sua"), dien san so tien cu, currentSalaryId = id
    
    Bam nut:
      neu currentSalaryId == -1 -> addExpense -> cap nhat currentSalaryId, doi nut thanh "Sua"
      neu currentSalaryId != -1 -> updateExpenseAmount(id, soluong moi)

### Xoa khoan chi
    Bam vao item trong RecyclerView
    -> AlertDialog: "Ban muon xoa khoan 'note' khong?"
    -> Bam Xoa: dbHelper.deleteExpense(id) -> loadData() -> updateSummary()
    -> Bam Huy: dong dialog, khong lam gi

### Bang: expenses - gia tri category va date

    category="variable"  date="yyyy-MM-dd"  -> chi phi phat sinh theo ngay
    category="fixed"     date="yyyy-MM"     -> chi phi co dinh THEO THANG (moi thang tu nhap)
    category="salary"    date="yyyy-MM"     -> luong thang
    category="income"    date="yyyy-MM-dd"  -> thu nhap khac (du phong)
